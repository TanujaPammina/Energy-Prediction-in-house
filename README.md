# Energy Prediction in House

This project focuses on **predicting heating and cooling energy consumption** before building a house to help save energy efficiently. Using historical data and machine learning techniques, the model estimates energy usage, enabling better energy planning and reducing waste.

## Live Demo

Check out the deployed application here:  
👉 [Energy Consumption Prediction App](https://energy-consumption-prediction-2-3.onrender.com)

Feel free to explore the app to see real-time predictions based on input parameters!

## Features

- Energy consumption prediction for heating and cooling
- User-friendly interface for inputting house parameters
- Data-driven insights to optimize energy use
